# API Testing Portfolio

A practical API testing portfolio developed with Python, Requests, and Pytest.

This project was created to practice and demonstrate automated testing concepts for REST APIs, including HTTP requests, response validation, data integrity, and automated test scenarios.

## 🛠️ Technologies

- Python
- Pytest
- Requests
- REST APIs
- JSON

## 🧪 Tests Covered

The project includes automated tests for:

- HTTP status code validation
- Response body validation
- Required field validation
- Data type validation
- Unique ID validation
- Unique email validation
- Response data integrity
- GET requests
- POST requests

## 🎯 Purpose

The main goal of this project is to develop practical skills in API testing and test automation using Python and Pytest.

It also serves as a portfolio project to demonstrate knowledge of automated API testing, test organization, assertions, HTTP methods, and JSON data manipulation.
